ℹ️ How Priority Rules Work

  1. AI analyzes the email and suggests an initial priority
  2. Rules are checked in this order:
    • If sender matches high-priority list → HIGH
    • If keywords found in subject/body → HIGH
    • If due date within threshold → HIGH
    • Otherwise → Use default priority
  3. Priority is applied to the action and shown in the actions list
